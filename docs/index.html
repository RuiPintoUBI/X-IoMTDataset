IoMT Cross Layer Dataset (X-IoMT)

A publicly available dataset for anomaly detection research in Internet of Medical Things (IoMT) environments. It provides cross-layer coverage across the perception, network, and application layers, and includes benign, malicious, and FGSM/PGD adversarially perturbed samples under L₂ and L∞ norms.

Dataset summary

X-IoMT addresses limitations of existing datasets that focus on a single layer or narrow attack type by providing cross-layer coverage across the perception, network, and application layers of IoT architectures. It contains both benign and malicious traffic, including adversarially perturbed samples generated using FGSM and PGD under L₂ and L∞ norms. These augmentations support evaluation of models under common and adversarial conditions, enabling development of robust anomaly detection with multi-layer visibility.

Reproducibility setup (seeds + environment)

Fixed random seeds: NumPy and scikit-learn = 42; TensorFlow = 42. Dataset generation and model training on a Linux workstation with NVIDIA GeForce RTX 5060 Ti GPU and an AMD-class CPU. Software: Python 3.10, scikit-learn 1.4, NumPy 1.26, pandas 2.1, TensorFlow 2.21.

At a glance

Version: ⚑ v1.1 (2026-01)
Labels: anomaly.layer, anomaly.name, anomaly.label
Capture scope: traffic between IoT nodes and servers/MQTT brokers
Intended use: anomaly detection, traffic classification, IoT/IoMT security research, benchmarking

Labels & layers

anomaly.layer: (0=Normal, 1=Perception, 2=Network, 3=Application)
anomaly.name: anomaly type/name (e.g., DoS, overheating, abnormal clinical data)
anomaly.label: 0 = Normal, 1 = Anomaly
