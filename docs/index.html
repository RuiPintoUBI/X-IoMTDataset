IoMT Cross Layer Dataset (X-IoMT)

A publicly available dataset for anomaly detection research in Internet of Medical Things (IoMT) environments, with cross-layer coverage across perception, network, and application layers, plus FGSM/PGD adversarial samples.

Dataset summary

X-IoMT is a publicly available dataset for anomaly detection in IoMT environments. It addresses the limitations of datasets that focus on a single layer or narrow attack types by offering cross-layer visibility across the perception, network, and application layers. It includes both benign and malicious traffic, plus adversarially perturbed samples generated with FGSM and PGD under L₂ and L∞ norms to evaluate robustness under common and adversarial conditions.

Reproducibility setup (seeds + environment)

All experiments used fixed random seeds for repeatability (NumPy and scikit-learn seed = 42; TensorFlow seed = 42). Dataset generation and model training ran on a workstation with an NVIDIA GeForce RTX 5060 Ti GPU and an AMD-class CPU on Linux. Software: Python 3.10, scikit-learn 1.4, NumPy 1.26, pandas 2.1, TensorFlow 2.21.

Labels

anomaly.layer (Perception, Network, Application)
anomaly.name (anomaly type/name)
anomaly.label (0 = Normal, 1 = Anomaly)

Capture scope

Traffic between IoT nodes and servers / MQTT brokers. Designed for multi-layer anomaly detection and benchmarking.

Use cases

Anomaly detection • traffic classification • IoT/IoMT security research • benchmarking • adversarial robustness evaluation.
